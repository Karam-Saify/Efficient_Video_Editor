# ADR-0010: Positioning: code-switching (ar/en/fr) first-class; Arabic-first launch
- **Status:** Accepted · **Date:** 2026-11-23 · **Decider:** Founder (after 3 independent stakeholder strategy memos) · **Door:** one-way-ish · **Review:** M1 gate
- **Process note:** Founder decision recorded directly; no T3 five-position vote was held. Positions may file dissent at the M1 gate.

**Decision:** Code-switching between Arabic, English and French is a first-class feature (ASR, captions, direction, fonts). Launch is Arabic-first. Extends ADR-0006 (multilingual, auto-detect).
