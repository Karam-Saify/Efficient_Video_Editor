# ADR-0013: Edit diffs are sensitive personal data
- **Status:** Accepted · **Date:** 2026-11-23 · **Decider:** Founder (after 3 independent stakeholder strategy memos) · **Door:** two-way · **Review:** M1 gate
- **Process note:** Founder decision recorded directly; no T3 five-position vote was held. Positions may file dissent at the M1 gate.

**Decision:** Edit diffs (a user's ops, revisions, prompts and timeline versions) are treated as sensitive personal data under `company/positions/05-assurance/DATA_POLICY.md`: minimised, access-logged, deletable on request, never used for training without explicit opt-in.
