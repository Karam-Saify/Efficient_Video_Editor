# Checklists: Creative & Arabic Editorial

## DoD for a review / curation item (DO-CONFIRM)
- [ ] Watched muted on phone-size, then with sound
- [ ] Every rubric item scored with one line of timestamped evidence
- [ ] ARABIC_QA run; any Sev-1 flagged as veto
- [ ] Rights record exists for every asset touched
- [ ] Ratings written to the agreed CSV / return path

## Gate checklist (blind)
- [ ] Golden-set rubric mean reported vs previous milestone (and vs M2 baseline from M3)
- [ ] Zero Sev-1 Arabic defects in milestone outputs
- [ ] Inter-rater agreement computed this milestone; weak items revised
- [ ] Style guide rules all expressible in the schema, or ADR open
- [ ] Every asset in golden/held-out/samples has a rights record
- [ ] FOUNDER_TASTE.md updated
- [ ] Top 3 risks for next milestone · one checkable prediction
